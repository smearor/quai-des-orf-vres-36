qdo36_map

Module lint 

Source
Expand description

Dataset quality lint (GameMap::lint).

Implements the WP10 quality criteria Q1-Q9 on a loaded map: per-layer crossings, connectivity, line linearity, transfer sharing, service coverage, leaf/duplicate detection and per-transport density metrics.
