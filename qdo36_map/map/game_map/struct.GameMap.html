pub struct GameMap { /* private fields */ }
Expand description

The validated Paris game graph.

Built once from the TOML dataset (MapToml); immutable for the lifetime of a game. All coordinates are map millimeters.

pub fn route_on( &self, from: StationId, to: StationId, transport: Transport, ) -> Option<Vec<StationId>>

Stations unreachable from the rest of the graph (BFS over neighbors).

A soft dataset-quality check, not a load error: an island is legal TOML but almost certainly a data bug (a Scotland Yard map must be one component). Bundled maps are asserted connected in tests; callers may warn on non-empty results. Shortest path between two stations along transport edges, weighted by straight-line distance - the drawn route of an edge that passes stations without stopping (metro lines routed through the taxi mesh).

Shortest path along the surface street mesh (taxi + bus edges), weighted by straight-line distance - the drawn route of a metro edge that passes stations without stopping.
