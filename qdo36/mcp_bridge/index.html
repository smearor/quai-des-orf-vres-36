Module mcp_bridge 

Source
Expand description

MCP bridge: publishes the app state snapshot the qdo36-mcp endpoint serves, and drains the command channel into the app-owned GameHost.

The GTK side writes a typed document into a watch channel and executes GameRequests on the main loop; the MCP thread reads the document and forwards commands - no GTK access from the server, ever (WP05 R5).
