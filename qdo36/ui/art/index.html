The generated SVG artwork (resources/art/): cached rsvg handles, name-to-stem mapping, and the draw spec.

resources/art/{family}/{city}/{style}/ holds the font-free SVGs produced by qdo36-artwork. Handles are loaded lazily and cached per path; missing files resolve to None so callers fall back to the StyleRenderer primitives.
