Functions§

controls
Builds one collapsible control menu per screen edge - each wrapped in a RotationWidget facing its own player, and each collapsed to a burger button until its side opens it (per-menu state). The handlers mutate the scene through the same mcp_bridge helpers the MCP commands use - always in sync.
side_menu 🔒
One edge’s menu: burger button plus the collapsible bar inside a RotationWidget rotated toward the edge’s player. The menu sections open inline below the bar (a drawer row) instead of a popover: GTK popovers are separate surfaces that cannot inherit the widget’s rotation.
