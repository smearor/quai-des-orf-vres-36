PoseAnimator - smooth transitions between anchor poses.

Sits between the logical AnchorState (tracked / virtual) and the rendered pose: small per-event deltas are followed with a frame-rate independent exponential blend (tracking mode), while large jumps - re-placement elsewhere or the first pose after the virtual fallback - run a timed ease (teleport mode) so the map visibly slides and rotates into place.
