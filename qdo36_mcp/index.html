Game-domain MCP server for Quai des Orfèvres 36.

rmcp server over Streamable HTTP exposing the app’s live state snapshot (anchor pose, map info) to agents - later: role-scoped agent play. The server reads a shared watch document the app publishes; it never touches GTK (WP05 R5).
