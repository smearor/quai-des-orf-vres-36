Expand description

One command for the game host.

The tool never mutates session state itself - it wraps the command into a crate::GameRequest whose oneshot carries the reply.

Variants§

§

NewGame

Deals a fresh game (phase: Deal → InProgress once Self::Begin arrives). None uses the loaded map’s defaults (GameConfig::for_map); Some deals with the given setup - needed for deal-shaping fields like detective count, ticket stocks or allow_undo, which SetConfig cannot change post-deal.

Fields

§config: Option<GameConfig>

Optional explicit setup; None = map defaults.

§

SetConfig

Adjusts reveal schedule and max rounds pre-game (Deal phase only).

Fields

§reveal: Option<RevealPreset>

Reveal preset override; None keeps the current choice.

§max_rounds: Option<RoundNumber>

Game length override; None keeps the current value.

§

Begin

Leaves the Deal phase - moves are accepted afterwards.

§

Join

Seats an agent under a role claim; issues a PlayerToken.

Fields

§claim: RoleClaim

Which seat the agent claims.

§

GameState

The role-scoped state for a token.

Fields

§token: PlayerToken

The player’s token.

§

LegalMoves

Legal destinations for a token’s role.

Fields

§token: PlayerToken

The player’s token.

§

Move

A move for a token’s role (the host enforces actor = role).

Fields

§token: PlayerToken

The player’s token.

§request: MoveRequest

The requested move; request.actor is overridden with the token’s role.

§

MapLint

Lint the loaded map dataset (quality criteria Q1-Q9).

§

Screenshot

A PNG screenshot of the app window. Handled by the app-side drain, not the game host - the session knows no window.

§

SceneLayout

Every drawn entity’s mm + px position under the current view transform (visual debugging).

§

Goto

Center the view on one station or frame a hop between two (app-side view state, not persisted).

Fields

§stations: Vec<StationId>

The stations to frame: one centers, two auto-fit.

§zoom: Option<MapScale>

Zoom override; None auto-fits for two stations and keeps the zoom for one.

§

SetView

Pan/rotate/zoom the view (app-side view state, not persisted).

Fields

§zoom: Option<MapScale>

Zoom factor; None keeps.

§rotate: Option<DisplayRotation>

Display rotation; None keeps.

§pan: Option<Vec2<Millimeters>>

Pan offset on the surface; None keeps.

§compass: Option<Vec2<Millimeters>>

Compass rose position on the map; None keeps.

§

ReloadMap

Reloads the city dataset from disk (dev iteration - no restart needed). App-side.

§

SetAnchor

Sets a virtual anchor pose on the surface - overrides the “place the tower” setup for headless/table-less runs. App-side.

Fields

§center: Vec2<Millimeters>

Anchor center on the surface.

§rotation_rad: Option<RotationRad>

Anchor orientation; None keeps upright.

§

SetParams

Global render factors (station/landmark/metro badge sizes, ring width, label font). App-side.

Fields

§station_scale: Option<ScaleFactor>

Station disc radius factor; None keeps.

§landmark_scale: Option<ScaleFactor>

Landmark pin size factor; None keeps.

§metro_scale: Option<ScaleFactor>

Metro line-badge size factor; None keeps.

§ring_width: Option<ScaleFactor>

Transport-ring stroke width factor; None keeps.

§label_scale: Option<ScaleFactor>

Label font size factor; None keeps.

§

SetLayers

Toggle scene layers (app-side render state).

Fields

§mask: LayerMask

Per-layer flags; None fields keep current values.

§

SetStyle

Switch the map artwork style at runtime (app-side render state, not persisted).

Fields

§style: StyleName

"comic", "belle_epoque" or "neon".
